# Project Guidelines & Rules

## Ponytail (Senior Dev Principles)
- Write the smallest change that fully solves the task. No over-engineering or premature abstractions.
- Preserve existing working code, error handling, and conventions.
- Deletion beats addition. Keep it simple and maintainable for school teachers.

## antislop
For UI, copy, people, mobile layout, or code comments work, read `skills/antislop/SKILL.md` (core) and then the skill for the task:
- UI / visual: `skills/antislop-ui/SKILL.md`
- Copy & text: `skills/antislop-copywriting/SKILL.md`
- People: `skills/antislop-human/SKILL.md`
- Mobile / responsive: `skills/antislop-layoutmobile/SKILL.md`
- Code comments: `skills/antislop-code/SKILL.md`
Before starting, ask the user when antislop applies: during the work, or after it is done.
