# Migrasi ke Supabase & Vercel

Aplikasi ini telah sepenuhnya diubah menjadi **Serverless Single Page Application (SPA)** menggunakan Vite dan Supabase. 
Artinya, aplikasi ini tidak lagi memerlukan server Node.js khusus dan dapat di-deploy ke Vercel atau GitHub Pages secara gratis tanpa batasan waktu nyala (uptime) atau batas ukuran unggahan dari Serverless Function (Vercel).

## 1. Setup Supabase
1. Buat proyek baru di [Supabase](https://supabase.com).
2. Pergi ke menu **SQL Editor** di Supabase, lalu jalankan SQL berikut untuk membuat tabel dan Storage:

\`\`\`sql
-- Buat tabel untuk Opsi (Kelas dan Materi)
create table public.options (
  id bigint generated by default as identity primary key,
  type text not null,
  name text not null
);

-- Buat tabel untuk mencatat file yang diunggah
create table public.files (
  id bigint generated by default as identity primary key,
  kelas text not null,
  materi text not null,
  nama text not null,
  filename text not null,
  storage_path text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Izinkan akses anonim untuk tabel (Supaya siswa bisa fetch opsi dan insert file)
alter table public.options enable row level security;
alter table public.files enable row level security;

create policy "Allow public read options" on public.options for select to anon, authenticated using (true);
create policy "Allow authenticated insert options" on public.options for insert to authenticated with check (true);
create policy "Allow authenticated delete options" on public.options for delete to authenticated using (true);

create policy "Allow public read files" on public.files for select to anon, authenticated using (true);
create policy "Allow public insert files" on public.files for insert to anon, authenticated with check (true);
create policy "Allow authenticated delete files" on public.files for delete to authenticated using (true);

-- Buat Storage Bucket untuk unggahan
insert into storage.buckets (id, name, public) values ('uploads', 'uploads', true);

-- Atur kebijakan keamanan Storage (Siswa dapat mengunggah)
create policy "Allow public uploads" on storage.objects for insert to anon, authenticated with check (bucket_id = 'uploads');
create policy "Allow public read uploads" on storage.objects for select to anon, authenticated using (bucket_id = 'uploads');
create policy "Allow authenticated delete uploads" on storage.objects for delete to authenticated using (bucket_id = 'uploads');
\`\`\`

3. Masuk ke menu **Authentication > Providers**, lalu aktifkan **Google**. Masukkan *Client ID* dan *Client Secret* dari Google Cloud Console Anda. (Anda sudah melakukan ini, ini langkah yang benar!)
4. Di Google Cloud Console (tempat Anda mendapatkan Client ID & Secret), pastikan Anda menambahkan URL Supabase (biasanya `https://<project-ref>.supabase.co/auth/v1/callback`) ke daftar **Authorized redirect URIs**.

## 2. Deploy ke Vercel
1. Unggah kode proyek ini ke repositori **GitHub** Anda.
2. Buka [Vercel](https://vercel.com) dan buat proyek baru (*Add New Project*), lalu hubungkan ke repositori GitHub tersebut.
3. Di bagian **Environment Variables** pada pengaturan Vercel, tambahkan dua variabel ini:
   - `VITE_SUPABASE_URL`: (Dapatkan dari Supabase: Project Settings > API > Project URL)
   - `VITE_SUPABASE_ANON_KEY`: (Dapatkan dari Supabase: Project Settings > API > Project API Keys (anon, public))
4. Klik **Deploy**!
